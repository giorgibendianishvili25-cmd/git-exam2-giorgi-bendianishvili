# Merge Conflict Resolution

## კონფლიქტის მიზეზი
კონფლიქტი წარმოიქმნა `master` განშტოებაში `change-title-2` ბრენჩის შეერთებისას, რადგან ორივე განშტოებაში (`change-title-1` და `change-title-2`) `index.html` ფაილის ზუსტად ერთი და იგივე სტრიქონი (`<h1>` ტეგში) იყო შეცვლილი განსხვავებული ტექსტით.

## მოგვარების გზა
VS Code-ის Merge Editor-ის დახმარებით მოვაგვარეთ კონფლიქტი, წავშალეთ Git-ის მარკერები. დავტოვეთ საბოლოო ვარიანტი, შევინახეთ ფაილი და შევასრულეთ `git add` და `git commit`.
